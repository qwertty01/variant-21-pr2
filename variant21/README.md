# Dependency Graph Visualizer (Вариант №21)

Инструмент визуализации графа зависимостей для менеджера пакетов Python (pip).

Готовые средства (менеджеры пакетов, библиотеки) для получения зависимостей **не используются**.

## Общее описание

CLI-приложение строит граф зависимостей пакета Python (формат pip) и визуализирует его.

Основные возможности:
- Чтение конфигурации из XML-файла
- Получение прямых и транзитивных зависимостей
- Фильтрация пакетов по подстроке
- Ограничение глубины анализа
- Обработка циклических зависимостей
- Режим тестирования на искусственном графе
- Вывод порядка загрузки зависимостей
- Визуализация в формате D2 + SVG
- ASCII-дерево (опционально)

## Параметры конфигурации (config.xml)

| Параметр              | Описание                                              |
|-----------------------|-------------------------------------------------------|
| package               | Имя анализируемого пакета                             |
| repo_url              | URL репозитория или путь к файлу тестового репозитория|
| test_mode             | Режим работы с тестовым репозиторием (`true`/`false`) |
| version               | Версия пакета                                         |
| output_file           | Имя файла с изображением графа (без расширения)       |
| max_depth             | Максимальная глубина анализа зависимостей             |
| filter_substring      | Подстрока для фильтрации пакетов (исключаются)        |

Пример `config.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <package>requests</package>
    <repo_url>https://pypi.org/simple/</repo_url>
    <test_mode>false</test_mode>
    <version>2.31.0</version>
    <output_file>deps</output_file>
    <max_depth>3</max_depth>
    <filter_substring>test</filter_substring>
</config>
```

## Описание функций

### Основные модули

- `src/config.py` — загрузка и валидация XML-конфигурации
- `src/fetcher.py` — получение данных о зависимостях (pip / тестовый репозиторий)
- `src/graph.py` — построение графа (DFS без рекурсии), фильтрация, циклы, порядок загрузки
- `src/visualizer.py` — генерация D2, SVG, ASCII-дерева
- `src/main.py` — точка входа CLI

### Алгоритмы

- **Построение графа**: DFS без рекурсии (явный стек)
- **Циклы**: отслеживание пути посещения
- **Порядок загрузки**: топологическая сортировка (с учётом циклов)
- **Фильтрация**: исключение пакетов, содержащих заданную подстроку

## Команды сборки и запуска

### Требования

- Python 3.10+
- graphviz (для рендера SVG из D2 при наличии d2)

```bash
# Установка зависимостей проекта (только для запуска)
pip install -r requirements.txt
```

### Запуск

```bash
# Основной запуск
./run.sh

# или напрямую
python -m src.main --config config.xml

# Режим тестирования
python -m src.main --config config_test.xml
```

### Тесты

```bash
python -m pytest tests/ -v
```

## Примеры использования

### 1. Реальный пакет (requests)

```bash
python -m src.main --config config.xml
```

### 2. Тестовый репозиторий

```bash
python -m src.main --config config_test.xml
```

### 3. Вывод только порядка загрузки

При установленном флаге `show_load_order` в конфигурации (или через расширение) выводится порядок.

## Сравнение с штатными инструментами

Результаты сравнивались с `pip show` / `pipdeptree`. Возможные расхождения:
- Отсутствие полной информации о extras
- Ограничение глубины
- Фильтрация по подстроке
- Использование только direct dependencies из метаданных

## Этапы выполнения

1. Минимальный прототип + конфигурация XML
2. Сбор данных (Python / pip)
3. Основные операции (DFS без рекурсии, фильтр, глубина, циклы, тест-режим)
4. Порядок загрузки зависимостей
5. Визуализация D2 + SVG
